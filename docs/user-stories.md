# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a Scrum Master, I want to input our remaining backlog size, so that I can generate a probabilistic delivery forecast
2. As a Project Manager, I want to view the delivery forecast at 85% and 95% confidence levels, so that I can communicate objective risk to stakeholders
3. As an Agile team member, I want the system to randomly pull from past sprint throughputs 10,000 times, so that the simulation accounts for real-world delays
